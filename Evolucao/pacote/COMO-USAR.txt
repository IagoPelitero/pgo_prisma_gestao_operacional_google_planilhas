COMO USAR ESTE PACOTE
=====================

São três arquivos, em vez dos 19 do repositório. No editor do Apps Script:

  1. Apague os arquivos que já estiverem lá (menu de cada um > Excluir).
     Sobra o Codigo.gs que o Apps Script cria sozinho — use ele no passo 2.

  2. Arquivo .gs chamado "Codigo"      <- cole Codigo.gs
  3. Arquivo HTML chamado "Index"      <- cole Index.html
  4. Arquivo HTML chamado "SemAcesso"  <- cole SemAcesso.html

ATENÇÃO AOS NOMES: no Apps Script o arquivo se chama "Index", e não
"Index.html" — sem extensão, sem acento, com as maiúsculas iguais.

  5. O FUSO DO PROJETO: Configurações do projeto (a engrenagem) > Fuso
     horário > (GMT-03:00) Horário de Brasília - São Paulo. Fora dele, toda
     data digitada recua um dia. (Quem preferir: marque "Mostrar o arquivo de
     manifesto appsscript.json" e cole o appsscript.json deste pacote.)
  6. Publique como aplicativo da web (executar como você).
  7. Execute instalarRECC() UMA vez, sobre uma planilha VAZIA.
  8. Execute diagnosticoRECC() para conferir tudo — ele confere os dois fusos.

SE A PLANILHA JÁ FOI USADA
--------------------------
O instalarRECC() RECUSA rodar sobre planilha com dado, de propósito — ele
criaria abas por cima do que já existe. Escolha um dos dois caminhos:

  COMEÇAR DO ZERO (o mais simples)
  Apague as abas do sistema na planilha: BASE_RET, BASE_MESA, USUARIOS,
  CORRETORAS, SUSEP_BLOQUEADAS, CANAIS, CAMPOS, CATALOGO,
  PAINEIS, ANALISES, CONFIG, AUDITORIA, ERROS — e as ANALISE_* que houver.
  Deixe UMA aba qualquer (o Sheets não aceita planilha sem aba nenhuma).
  Depois rode instalarRECC().

  Pelo editor: Arquivo > Configurações do projeto > e também limpe as
  propriedades do script, onde moram as sequências de Id. Sem isso, a
  contagem de Id continua de onde parou — o que não quebra nada, mas
  faz o primeiro caso novo nascer com Id 47 em vez de 0.

  MANTER O QUE JÁ ESTÁ LÁ
  Rode migrarParaCanais() UMA vez. Ela renomeia as abas que mudaram de
  nome, acrescenta as colunas novas e leva as sequências de Id junto.
  Não apaga nada, e pode rodar duas vezes sem estragar.

O QUE TEM DENTRO
----------------
Codigo.gs      7 arquivos: Base.gs, Cadastros.gs, Casos.gs, Config.gs, Entrada.gs, Indicadores.gs, Instalacao.gs
Index.html     10 telas: Estilos, Comuns, Trabalho, CadastrarCaso, BuscarCaso, TabelaCorretoras, Importacao, Produtividade, Configuracoes, Aplicacao
SemAcesso.html a tela de acesso negado, servida sozinha pelo doGet

NÃO EDITE ESTES TRÊS ARQUIVOS. Eles são gerados. Mexa no repositório e rode
node Evolucao/Testes/gerar-pacote.js de novo.

Eles vêm SEM OS COMENTÁRIOS, para pesarem a metade na colagem. A explicação
de cada regra continua no repositório, arquivo por arquivo.
